# 6-Folder Obsidian Vault Template

This repository contains the structured folder layout and core templates designed to turn your digital notes from an information graveyard into an active synthesis engine.

## 📖 The Methodology

This system is built on the principles of Zettelkasten and PARA, stripped down to what actually works under heavy research and automation constraints.

## 📂 Vault Structure

* **`1- Rough-notes/` (The Inbox)** – The raw core dump. Designed to be messy. Nothing stays here forever.
* **`2- Source-material/` (The Library)** – Immutable records (books, video summaries, clipped specs) organized by media type.
* **`3- Tags/` (The Anchors)** – Dedicated markdown files acting as concept anchors instead of chaotic inline hashtags.
* **`4- Indexes/` (The Dashboards)** – Maps of Content (MOCs) serving as entry points for broad topics.
* **`5- Templates/` (The Molds)** – Standardization files for atomic notes, daily logs, and project PRDs.
* **`6- Atomic-notes/` (The Core)** – Evergreen, single-idea notes cleanly formatted and heavily linked.

---

## 🚀 Getting Started

1. Clone this repository directly into your local machine.
2. Open Obsidian, select "Open folder as vault," and point it to the cloned directory.
3. Configure your templates via Settings -> Templates to point to the `5- Templates/` directory.
